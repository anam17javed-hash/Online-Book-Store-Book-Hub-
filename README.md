📚 Online Book Store Website

📌 Project Overview

Online Book Store is a web-based e-commerce application developed as my Final Year Project. The system provides an easy and convenient platform for users to browse, search, and purchase books online.

The project includes both user-side and admin-side functionality, with a database-driven backend for managing users, books, carts, orders, and other store operations.

🛠️ Technologies Used

- HTML5 – Website structure
- CSS3 – Styling and responsive user interface
- JavaScript – Interactive features and client-side functionality
- PHP – Backend and server-side functionality
- MySQL – Database management

✨ Features

👤 User Features

- User Registration
- User Login & Logout
- Browse available books
- Search for books
- View book details
- Add books to cart
- Update/remove items from cart
- Checkout
- Place orders
- Payment functionality
- View order information

🔐 Admin Features

- Admin Login
- Admin Dashboard
- Add new books
- Update book information
- Delete books
- Manage book inventory
- Manage users
- Manage orders
- Monitor store activities

🛒 Shopping & Order System

The website provides a complete shopping flow:

Browse Books → Search Book → View Details → Add to Cart → Checkout → Payment → Order

🗄️ Database

MySQL is used as the database management system to store and manage:

- User information
- Book details
- Cart data
- Orders
- Payment-related information
- Admin/store data

⚙️ Installation & Setup

1. Clone the Repository

git clone https://github.com/your-username/online-book-store.git

2. Setup Local Server

Install XAMPP and start:

- Apache
- MySQL

3. Add Project Files

Copy the project folder into:

xampp/htdocs/

4. Setup Database

1. Open phpMyAdmin
2. Create a new MySQL database
3. Import the SQL database file included in the project
4. Update the database connection settings in the PHP configuration file if required

5. Run the Website

Open your browser and visit:

http://localhost/Online-Book-Store/
